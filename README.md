# 미러미 (MirrorMe)

내 동선과 폰 사용을 기록해서 하루 타임라인과 루틴을 보여주는 안드로이드 앱입니다.
모든 기록은 폰 안에만 저장되고 인터넷으로 보내지 않습니다.

## 폰에 설치하기

1. PC에 [Android Studio](https://developer.android.com/studio)를 설치합니다.
2. 이 폴더(`MirrorMe`)를 압축 해제한 뒤 Android Studio에서 **Open**으로 엽니다.
   처음 열 때 필요한 도구를 자동으로 내려받느라 몇 분 걸립니다.
3. 폰에서 **개발자 옵션 → USB 디버깅**을 켭니다.
   (설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호를 7번 누르면 개발자 옵션이 생깁니다.)
4. 폰을 USB로 연결하고 Android Studio 위쪽의 ▶ 실행 버튼을 누릅니다.

## 처음 실행하면

설정 탭에서 순서대로 허용합니다.

1. 위치 허용
2. 위치 "항상 허용" (앱을 닫아도 기록)
3. 사용 기록 접근 → 목록에서 "미러미" 켜기
4. 알림 허용
5. 배터리 최적화 제외 (삼성 폰은 "제한 없음"으로. 안 하면 며칠 뒤 기록이 끊길 수 있음)

그다음 "동선 기록" 스위치를 켜면 됩니다.

## 무엇을 기록하나

| 항목 | 방법 | 주기 |
|---|---|---|
| 위치 | 와이파이·기지국 위주(배터리 절약) | 3분마다 |
| 앱 사용 | 안드로이드 사용 기록(UsageStats) | 15분마다 옮겨 저장 |
| 화면 켜짐/꺼짐 | 같은 사용 기록 | 15분마다 |

## 무엇을 보여주나

- **오늘**: 머문 장소 순서, 장소별로 많이 쓴 앱, 화면 사용 시간
- **루틴**: 평일/주말 수면 시간, 시간대별로 주로 있는 곳, 특정 요일에만 가는 곳(예: 화·목 헬스장), 시간대별 앱 습관
- **장소**: 자동으로 묶인 장소 목록. 이름을 바꿀 수 있고, 집과 회사는 자동으로 이름이 붙습니다.
- **요약 공유**: 루틴을 글로 정리해 AI에 넘길 수 있습니다. 좌표는 빠지고 장소 이름만 들어갑니다.

일주일 정도 쌓이면 루틴이 또렷해집니다.

## 코드 구조

```
app/src/main/java/dev/mirrorme/
  data/        Room DB (위치, 앱 사용 구간, 화면 이벤트, 장소)
  tracking/    TrackingService(위치), UsageCollector(앱 사용), UsageSyncWorker(15분 주기), BootReceiver
  analysis/    Analysis.kt(머문 곳 감지·타임라인·루틴 분석), Repo.kt(화면용 데이터, 요약 글)
  ui/          Compose 화면 (오늘, 루틴, 장소, 설정)
```

조절하고 싶은 값:
- 위치 주기: `TrackingService.INTERVAL_MS`
- "머문 곳" 기준(반경 120m, 10분): `StayDetector.RADIUS_M`, `MIN_STAY_MS`
- 같은 장소로 묶는 거리(150m): `Repo.PLACE_RADIUS_M`
